# 💫 About Me:
I’m a 17-year-old developer still in high school, building full-stack applications, backend systems, tools, and large-scale projects. I work across different technologies and enjoy creating things that are actually useful rather than just making projects for the sake of it. A lot of what I build is focused on tools, systems, and services that people can use now or may need down the road. I’m constantly working on new ideas, experimenting with different technologies, and turning concepts into real, working projects.
